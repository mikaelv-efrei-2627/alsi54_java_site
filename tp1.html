1 Compiler et exécuter du code avec le JDK

  1. Installez Oracle 25: https://www.oracle.com/java/technologies/downloads/#jdk25-windows

    1. ouvrez une ligne de commande et testez l’installation avec java -version

  2. Créez un répertoire “java_tp1”

  3. Dans ce répertoire, créez un fichier PremierProgramme.java avec le contenu suivant:

    /** 
 * Ce programme imprime
 * "Hello World" sur la sortie standard
 */
public class PremierProgramme {
    public static void main(String[] args) {
        // imprime sur la sortie
        System.out.println("Hello World!"); 
    }
}

  4. ouvrez une ligne de commande windows et compilez le programme avec javac PremierProgramme.java

  5. tapez dir. Qu’observez-vous ?

  6. lancez le programme avec java PremierProgramme

  7. affichez le bytecode désassemblé avec javap -v PremierProgramme.class. Ne cherchez pas trop à comprendre les instructions bytecode, cet exercice montre que notre code Java a été compilé en instructions élémentaires compréhensibles par la JVM.

  8. générez la documentation

    1. créez un répertoire “doc”: mkdir doc
    2. générez la documentation avec javadoc PremierProgramme.java -d doc
    3. Ouvrez le fichier doc/index.html produit avec un navigateur
    4. Pouvez-vous retrouver la description du programme ?

  9. Modifiez la ligne 8 de votre programme pour qu’il affiche le premier argument passé à la fonction main:

    /** 
 * Ce programme imprime
 * "Hello {arg[0]} !" sur la sortie standard
 */
public class PremierProgramme {
    public static void main(String[] args) {
        // imprime sur la sortie
        System.out.println("Hello " + args[0] + " !"); 
    }
}

  10. Exécutez le programme en passant un argument: java PremierProgramme "Le Monde"

2 Utiliser JShell pour tester du code rapidement

JShell est un outil fourni depuis le JDK 9. JShell permet d’écrire du code Java (expressions, instructions, déclaration, …) qui est évalué individuellement sans avoir besoin de le placer dans une classe ou une méthode. C’est un outil de type “REPL” (Read-Eval-Print-Loop) semblable à celui de Python. Ce type d’outil est très pratique pour explorer une API, expérimenter du code ou pour apprendre un langage.

  1. Lancez JShell avec la commande jshell

  2. L’invite suggère de lire l’introduction. Tapez la commande /help intro

  3. Tapez ensuite /help pour avoir la liste de toutes les commandes

  4. Exécutez les lignes suivantes, et observez les résultats:

    2 + 2
int a, b
a = 2
b = 3
int c = a * b
c > 3
c++
System.out.println("Hello world")

  5. Tapez /list pour revoir l’historique des commandes

  6. Repérez le numéro d’instruction correspondant à c++ et exécutez la à nouveau avec /<numéro>. Par exemple si c’est la no 8, tapez /8.

  7. Copiez le code suivant avec ctrl-c:

    for (int i = 0; i < 5; i++) {
    if (i % 2 == 0) {
        System.out.println(i + " est pair");
    }
}

  8. Pour coller du code multi-ligne dans JShell, il faut d’abord le mettre en mode édition. Tapez /edit puis collez et exécutez le code précédent.

  9. Essayez les différents éléments de syntaxe présentés en cours:

    1. opérateurs arithmétiques
    2. opérateurs relationnels
    3. opérateurs logiques
    4. instructions conditionnelles
    5. boucles

  10. Déclarez une classe Person, comme vu en cours

  11. instanciez des objets de la classe

  12. utilisez ses attributs et méthodes

Tip

Dans JShell, si vous n’avez qu’une instruction par ligne, il n’est pas nécessaire de la terminer par un ;. Par contre vous pouvez taper plusieurs instructions sur une seule ligne en les séparant avec ;.

3 Premier projet avec IntelliJ Idea

  1. Suivez la procédure décrite dans Moodle pour installer IntelliJ: Procédure inscription JetBrains

  2. Créez un nouveau projet: IntelliJ IDEA First Java Program

  3. Lancez le programme.

    1. Quel fichier est produit après le “build” ? Où est-il situé ?
    2. Quel programme est exécuté en ligne de commande ?
    3. Quels sont ses arguments ?

  4. Modifiez le programme pour demander à l’utilisateur de saisir un nom, en utilisant la classe Scanner:

    import java.util.Scanner;

public class MyClass {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("Enter your name: ");
        String name = scanner.nextLine();
        System.out.println("Hello " + name + " !");
    }
}

3.1 Quelques raccourcis utiles

Essayez les raccourcis suivants:

Raccourci Description Utilisation
CtrlQ Quick documentation curseur sur une classe, attribut ou méthode puis tapez le raccourci
Ctrl click ou CtrlB Declaration curseur sur une classe, attribut ou méthode puis tapez le raccourci
CtrlAlt← Back après avoir fait ctrl-click, utiliser ce raccourci pour revenir
CtrlShiftBackspace Last edit location tapez du code, naviguez vers d’autres classes puis revenez au point de départ
CtrlN Navigate class tapez le raccourci, puis saisir le nom d’une classe comme String
CtrlF12 File structure dans une classe, tapez le raccourci, puis saisir le nom d’une méthode ou attribut pour naviguer vers sa définition
CtrlShiftF Find in files tapez le raccourci, puis du texte contenu dans un fichier
shiftshift search everywhere recherche une commande ou setting IntelliJ, ou une classe, fichier du projet, …

Avec de l’habitude, ils vont vous permettre de naviguer rapidement dans votre code mais aussi dans les API du JDK.

4 Jeu de rôle

Lors de ce TP, nous allons créer un petit jeu sous format texte. L’utilisateur pourra créer un personnage puis le faire évoluer sur un plateau. Lorsque le joueur rencontrera des ennemis, il y aura une phase de combat tour à tour avec des pertes de points de vie aléatoires.

4.1 Préparation

Utilisez le lien moodle pour créer votre projet sur GitHub classroom. Vous devrez commit & push votre code à la fin du TP.

4.2 Classe Plateau

  1. Créez un package jeu
  2. Dans ce package, créez une classe Plateau contenant les attributs char[][] grille, int largeur, int hauteur.
  3. Implémentez un constructeur qui prend en paramètre la largeur et la hauteur, et qui initialise la grille avec des caractères .
  4. Implémentez une méthode afficher, qui va imprimer la grille sur la console
  5. Créez une classe JeuMain, contenant une méthode principale main qui crée un plateau et l’affiche. Exécutez le programme.

4.3 Classe Personnage

  1. Dans le package jeu, créez une classe Personnage avec les attributs int ligne, int colonne et char symbole
  2. Implémentez un constructeur prenant 3 paramètres pour initialiser les 3 attributs
  3. Implémentez une méthode public void deplacer(int dligne, int dcolonne) qui va modifier les coordonnées ligne et colonne
  4. Ajoutez les “getters” pour les attributs: créez 3 méthodes
    1. public int getLigne()
    2. public int getColonne()
    3. public char getSymbole()

4.4 Ajouter le Personnage au Plateau

Dans la classe Plateau:

  1. Ajoutez un attribut joueur de type Personnage
  2. Modifiez le constructeur de Plateau pour initialiser l’attribut joueur en le positionnant au centre de la grille.
  3. Modifiez la méthode afficher pour afficher le joueur
  4. Ajoutez une méthode public void deplacerJoueur(int dligne, int dcolonne) qui va déplacer le joueur dans la grille. Pensez à tester les limites de la grille. Le déplacement ne doit pas avoir lieu si il fait déplacer le joueur en dehors de la grille.

Dans la classe JeuMain:

  1. Testez les déplacements en ajoutant le code suivant:
// à gauche
plateau.deplacerJoueur(0, -1);
plateau.afficher();
// en haut
plateau.deplacerJoueur(-1, 0);
plateau.afficher();
// à droite
plateau.deplacerJoueur(0, 1);
plateau.afficher();
// en bas
plateau.deplacerJoueur(+1, 0);
plateau.afficher();

4.5 Déplacement au clavier

Nous allons ajouter de l’interactivité en permettant à l’utilisateur de déplacer le personnage en utilisant le clavier. Sur un clavier AZERTY, les touches utilisés seront :

Touche Déplacement
z haut
q gauche
s bas
d droite
x quitter le jeu
  1. Dans JeuMain, utilisez la classe Scanner pour demander à l’utilisateur de saisir un déplacement, puis déplacez le joueur dans la grille.
  2. Mettre ce code dans une boucle qui se termine lorsque l’utilisateur saisit x.

4.6 Afficher des Ennemis

Pour rendre le jeu un peu plus intéressant, nous allons ajouter des ennemis qu’il va falloir éviter. Les ennemis vont se déplacer aléatoirement. En cas de collision, le joueur perd la partie.

  1. Dans la classe Plateau, ajoutez un tableau d’ennemis.
  2. Initialisez un certain nombre d’ennemis dans le constructeur, avec des positions arbitraires.
  3. Implémentez une méthode private void placerPersonnage(Personnage personnage) qui va placer un personnage (joueur ou ennemi) sur la grille.
  4. Modifiez le constructeur pour placer le joueur et les ennemis en utilisant la méthode placerPersonnage.
  5. Testez votre programme.

4.7 Faire bouger les ennemis

Nous allons maintenant faire bouger les ennemis aléatoirement. Dans la classe Plateau:

  1. Implémentez la méthode private int getRandomNumber(int max) qui va renvoyer un entier aléatoire n avec 0 <= n < max. Vous devrez utiliser la méthode du JDK Math.random()
  2. Implémentez public void deplacerPersonnage(Personnage personnage, int dligne, int dcolonne) qui pourra être appelée pour déplacer avec le joueur ou les ennemis. Modifiez deplacerJoueur pour appeler cette nouvelle méthode.
  3. Implémentez une méthode public void deplacerEnnemi(Personnage ennemi) qui va aléatoirement déplacer un ennemi. Vous devrez tirer un nombre au hasard, et en fonction du résultat déplacer à gauche, bas, haut, droite, ou pas du tout.
  4. Implémentez une méthode public void deplacerEnnemis(), qui va déplacer tous les ennemis.
  5. Modifiez JeuMain pour appeler notre nouvelle méthode deplacerEnnemis() et testez si elle fonctionne comme attendu.

4.8 Détection de collision

Afin de déterminer si la partie est perdue, il faut détecter si le joueur rencontre un ennemi.

  1. Dans la classe Personnage, implémentez une méthode public boolean memeCase(Personnage autre) qui renvoie true si autre est sur la même case que this.
  2. Dans la classe Plateau, ajoutez une méthode public boolean detecterCollision() qui renvoie true si le joueur est sur la même case qu’un ennemi.
  3. Modifiez JeuMain pour terminer le jeu et afficher un message si le joueur rencontre un ennemi.

4.9 Idées d’améliorations

Si il vous reste du temps, vous pouvez améliorer ce jeu de plusieurs manières:

  • ajouter des obstacles
  • ajouter des pointsDeVie à la classe Personnage pour ne pas mourir immédiatement.
  • permettre d’attaquer les ennemis. Les ennemis peuvent aussi avoir des points de vie.
  • ajouter des armes sur le plateau. Chaque arme a un attribut pointsAttaque qui fait perdre plus ou moins de points de vie.
  • rendre les ennemis plus intelligents: ils doivent se diriger vers le joueur.
Tip

Pour effacer la console après chaque saisie, vous pouvez utiliser le code suivant:

System.out.print("\033[H\033[2J");
System.out.flush();

Par contre cela ne fonctionne pas dans la console d’IntelliJ. Il faut lancer le programme depuis une ligne de commande windows.
